  2. Baseline: send it and inspect the answer, Tool Activity, and Prompt Similarity.

  4. Change one learning-card field, apply it, then repeat the same choice/request again.

Final explanation: what changed because of the instruction, what changed because of the learning card, how similar your next prompt was to previous agent wording, and — in Multi-Agent mode — what the Evaluator Agent concluded about your contribution.
